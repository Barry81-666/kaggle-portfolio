# Coral Reef Object Detection with YOLOv5 and WBF

My published notebook combines YOLOv5 detections with weighted box fusion in the Great Barrier Reef competition inference API.

## Source and Contribution

[Original Kaggle notebook](https://www.kaggle.com/code/handudu/yolov5-wbf), version ID `87726774`. Fork of parent kernel `24646241`; the parent's author and public URL were unavailable in the source snapshot.

## Running and Interpreting the Archive

The notebook requires the historical Great Barrier Reef competition API and model inputs, four of which were private.

Data and model weights are not included.
