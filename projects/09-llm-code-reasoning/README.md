# Mathematical Reasoning with Code Execution

My published notebook is an annotated learning and debugging study of DeepSeekMath-style mathematical reasoning with generated Python execution. Some cells operate on a single example; these are not a benchmark evaluation.

## Source and Contribution

[Original Kaggle notebook](https://www.kaggle.com/code/handudu/aimo1-20th), version ID `224999934`. Fork of [AbdurRafae](https://www.kaggle.com/code/abdurrafae/improved-code-interpretation).

## Running and Interpreting the Archive

This annotated fork executes model-generated Python in subprocesses and includes debugging code. The "20th" in its original title refers to an upstream solution, not my rank. It requires the historical model and GPU environment.

Inspect [notebook.ipynb](notebook.ipynb) and the original Kaggle Input list before configuring data and dependencies. Historical names, input dependencies and source hashes are retained in [provenance](../../meta/projects/09-llm-code-reasoning/provenance.json); shared handling details are in [archive notes](../../docs/ARCHIVE_NOTES.md).
