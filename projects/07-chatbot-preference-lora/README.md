# Multilingual Preference Prediction with Gemma and LoRA

My published notebook uses Gemma inference with PEFT/LoRA adapters for multilingual response-preference prediction. The notebook uses two GPUs and combines predictions after swapping response order; some explanatory Markdown describes alternative code rather than executed cells.

## Source and Contribution

[Original Kaggle notebook](https://www.kaggle.com/code/handudu/lmsys-peft0-14-0), version ID `217218292`. Published from my Kaggle account; credits to other authors inside the source are kept intact.

## Running and Interpreting the Archive

The notebook requires specific offline wheels, a base model, two GPUs and LoRA weights; three inputs were private in the source snapshot. Model loading and inference were not rerun.

Data and model weights are not included.
